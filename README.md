# 🚑 RESQ

### AI-Powered Medical Emergency Intelligence Platform

**RESQ** is a Kerala-focused platform designed to improve emergency medical response by connecting **citizens, ambulances, emergency responders, and hospitals** in real time.

## ✨ Features

* 🤖 AI-based emergency severity/triage assistance
* 📍 Real-time ambulance location tracking
* 🚑 Smart emergency response coordination
* 🗺️ Route assistance for ambulances
* 🏥 Hospital pre-alert with patient information
* ⚡ Real-time communication

## 🛠️ Tech Stack

* **Frontend:** Next.js, React
* **Backend:** Node.js, Express
* **AI:** Python, TensorFlow
* **Database:** PostgreSQL, Redis
* **Real-Time:** WebSockets, MQTT

## 🔄 How It Works

**Emergency Report → AI Triage → Ambulance Dispatch → Route Assistance → Hospital Pre-Alert → Patient Arrival**

## 🎯 Goal

To reduce delays in emergency medical response and help hospitals prepare for incoming patients.
